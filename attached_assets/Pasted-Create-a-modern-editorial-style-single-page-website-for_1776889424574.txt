Create a modern, editorial-style single-page website for a Portuguese digital agency called "Web Step - Tech Solutions" using React + TypeScript + Tailwind CSS.

## Design Style
- Inspired by BEHS.pt: pitch black background (#000000), bold editorial typography, minimal UI
- Color palette: black (#000000), white (#ffffff), red (#ef4444 / red-600), accent blue (#0800FF) for CTA buttons only
- Typography: ultra-bold/black font weights (font-black), large display text (text-7xl to text-9xl)
- Layout: grid-based with 1px white/10 separators between cards, no rounded corners on key elements
- Decorative elements: red horizontal lines (h-px or h-0.5) as section accents, red vertical line on hero left edge, red dots as label indicators

## Technical Details
- React functional components, TypeScript
- Tailwind CSS only for styling
- Lucide React for icons
- Smooth scroll between sections using getElementById
- Mobile responsive with hamburger menu
- All sections: id="home", id="services", id="portfolio", id="process", id="about", id="contact"
- Logo file: /logo.png (place in public folder)
- Portfolio image: /elitesite.png (place in public folder)
- All text in European Portuguese (PT-PT)
